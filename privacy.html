Privacy Policy

Northsignal Studio · last updated 23 September 2026

Who this covers

Northsignal Studio ("the app") is a personal tool used by one person: its owner. It has no other users, no sign-up and no accounts. The owner is the only person who authorises it and the only person whose data it touches.

What the app accesses

With the owner's consent, the app uses these Google API scopes on the owner's own YouTube channels:

  • youtube.upload — upload videos to the owner's channels.
  • youtube.readonly — read the owner's channel list, to verify the right channel before an upload.
  • yt-analytics.readonly — read view and audience statistics for the owner's own videos.

What is stored, and where

  • The OAuth tokens Google issues are stored in a file on the owner's own computer. They are not sent anywhere else.
  • The videos the app creates, and the view counts it reads back, are stored in a local database on the same computer.
  • There is no server, no hosting account and no third-party analytics behind the app. This website is static and sets no cookies.

What is shared

Nothing. Data obtained through Google APIs is not sold, not transferred to anyone, and not used for advertising, profiling or training any model. It is used only to publish the owner's own videos and to show the owner how they perform.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

The owner can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the token file on the computer removes the app's access immediately, and deleting the local database removes the stored statistics. Since no data leaves that computer, there is nothing to request from anyone else.

Children

The app is not directed at children and collects no data from anyone other than its owner.

Changes

If what the app does changes, this page is updated and the date above changes with it.
